# M4b · 法宝、古宝与寻宝

从 `ff4adf8` 继续。目标是让「秘境挂机取得资源 → 寻宝与收集 → 养成 → 回到战场」成为可玩的循环。2026-09-07 开始实施；验收结果在文末补齐。

## 对标依据

- [官方洞府介绍](https://xian.leiting.com/news/3.html)：洞府承担修炼与养成入口，本期把现有修炼页补成可进入法宝、古宝、寻宝、日常的枢纽。
- [官方古宝套装介绍](https://xian.leiting.com/news/175.html)：特定三件古宝的收集可以形成套装。本期古宝收藏即提供加成，不采用旧交接中的六槽被动饰品设计。
- [官方主动古宝公告](https://xian.leiting.com/news/228.html)：原作存在主动与被动古宝，升星和注灵是不同成长轴。本期先完成被动收藏，主动古宝后续实现。
- [官方探宝保底公告](https://xian.leiting.com/news/389.html)：已核实的是特定活动的限定保底，不能推出常驻池统一概率。本作下列概率、价格和保底是自定平衡规则。
- [官方免费探宝公告](https://xian.leiting.com/news/632.html)：免费探宝与境界相关，本期采用容易理解的「两池各每日免费一次」，不声称完全复刻原作配额。

原作另有体法双修、炼丹炼器、主动古宝、本命器灵、灵兽等系统；这些不因本期页面出现而被视为已实现。

## 本期规则

- 法宝：20 件，包含 2 件凡阶入门、6 蓝、6 紫、4 金、2 红；铃、塔、链、印、幡、盾六形制。本命槽独立施放，两个辅槽提供属性。等级上限 100、每十级关口消耗突破材料、注灵上限 10、五星觉醒。
- 古宝：24 件，蓝紫金红各 6 件。收藏即提供战斗或修炼加成，三件收集激活套装；重复取得本体碎片，碎片升星，星尘注灵。
- 寻宝：法宝和古宝两池，单抽 160 仙玉、十连 1500；基础概率蓝 60%、紫 30%、金 8.5%、红 1.5%。每次十连至少一件金及以上，各池独立 70 抽红色硬保底；红色重置本池计数。界面公示基础概率与保底会改变最终分布。
- 免费来源：两池每日各一次免费单抽、一次入门礼（清音铃与守心盾，铃自动填入空本命槽）、日常、首破境与首杀 BOSS 里程碑，后台也可发放。无真实付费。
- 日常：击杀 50、修炼 60 分钟、完成副本一次、主动论道一次、发送传音一次。按服务端 UTC 日期记账，奖励只能领取一次。
- 材料：仙玉、星尘、星辉石、天罡木；五星成本为五段 `10/20/40/80/120` 本体碎片。
- 兼容：旧法宝和灵宠装备保留原有作用，新藏品独立命名和存储，不自动复制、删除旧物品。随机词条、品阶晋升、主动古宝、独立灵兽仍是后续范围。

## 实现与验收边界

新进度保存在可选 `CharacterState.progression` 中，旧存档按需补默认值。抽取历史单独使用第 007 号迁移；请求 ID 保证同一抽取请求重试不重复扣款。扣款、发放、保底和记录必须在同一事务中完成，成功提交后才广播。

属性通过公共公式同时进入角色页、排行榜、公开档案、回合战斗与大地图；机器人使用确定性派生的新养成数据。本命法宝必须有实际战斗效果，不能只有面板加成。

验收使用已有测试工具与独立临时数据库，不写线上存档。检查保底边界、材料不足、重复与重试、每日重置、防重复领取、养成持久化，以及地图结算不会覆盖刚完成的养成。最后运行 `pnpm verify` 和真实服务端的浏览器流程，再按逻辑单元提交。

## 官网质感对照

用户在实施期间明确要求整体质感多参考[《一念逍遥》官网](https://xian.leiting.com/)。本轮直接打开官网并观察首屏与内容区：当前血修版本首屏采用朱红、墨紫和白色书法；常驻内容区采用黛蓝夜色、金粉云气、卷轴画框、山水和宣白标题。

游戏采用常驻内容区的黛蓝、暖白与细金作为连续底色，朱红用于主要动作和稀有强调。登录、洞府、顶底栏、图鉴、战斗 HUD 与弹层统一材质；后台保持原浅色。官网参考用于构图和色彩，未复制其标志、人物或活动画面。新洞府背景以当前官网截图作为绘制参考，器物图按本游戏名称分别制作，品级复用器型并以边框与文字区分。

额外收尾：机器人主动论道对同一真人增加十分钟共享冷却，使用既有战斗记录跨重启保留；真人主动论道不受此限制。
