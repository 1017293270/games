# 平面修仙界面：官方参考观察

核查日期：2026-09-07。以下是历史官方材料，不代表 2026 当前客户端逐项相同。只借鉴构图与层级；未把官方图片、角色、图标或音效复制进项目。静态截图不能证明动画节奏，下面的秒数均为本项目建议。

## 当前执行决定：圆球包头像

2026-09-07 用户进一步指定角色与怪物都采用“圆球包头像”，并要求任何游戏内容实施前必须先对照官方。执行前已重新打开[官方社交PK文章（2021-01-15）](https://xian.leiting.com/news/17.html)及[对应战斗展示图](https://xian.leiting.com/static/upload/editor/20210115/161069016436585503864082.jpg)：人物与怪物均用圆形肖像，细墨边、敌怪红黑环、主角金色阵圈与青色法术连接区分关系。该图是宣传合成展示，不能当成2026未加工实机。

本项目使用自己已有的头像素材，裁成圆球；自己有克制的金/青外圈，目标与Boss保留明确标识。圆球直径、呼吸幅度、轻微高光和描边粗细是按用户方向做的自定表现参数，不声称官方公开过这些具体数值。停止在战场使用全身修士与全身妖兽精灵。

1. **让山水画面成为主体，HUD 收边。** 官网 2020-12-03《洞府玩法介绍》的洞府实机图：顶部是一条窄资源栏，底部是圆形墨字入口，中间大部分留给浅灰山水；建筑、近水与远山主要靠墨色浓淡区分。**图像观察**：这里的质感来自平面绘画、层次和留白。**本项目建议**：上方短状态栏、下方战果与操作，减少大面积深色卡片；原创山水保持淡，人物和血条保持清晰。[官方文章](https://xian.leiting.com/news/3.html) · [洞府截图](https://xian.leiting.com/static/upload/editor/20201209/160750624936586479146551.jpg)

2. **动作落在画里，功能用小印章定位。** 同一洞府图中，聚灵阵、器室、丹房、药园以深褐圆印和短名称附着于相应建筑位置；修炼中的人物是山崖上的一个局部焦点。**官方明说**：洞府承担修炼、种植、炼丹、炼器、御兽。**本项目建议**：Boss/入口用少量地图印记；当前修士和锁定目标用形状、描边区分，不把每个功能扩成悬浮面板。[官方文章与实机图](https://xian.leiting.com/news/3.html)

3. **呼吸感集中在灵气焦点，不让整个 HUD 一起动。** 修炼室实机图以居中打坐人物、圆形法阵、青蓝灵气圈构成焦点，下方只有一条修为进度及少量操作。**图像观察**：局部高亮与较暗安静的背景形成对比；**不能从静态图判断其实际运动周期**。**本项目建议**：自角色淡光圈 3–5 秒轻微明暗起伏；云气 15–25 秒缓慢平移；受击/技能才短促闪现；文字和按钮保持稳定。这些时间是原创实现建议。[修炼室截图](https://xian.leiting.com/static/upload/editor/20201209/160750627436586479142213.jpg) · [所在官方文章](https://xian.leiting.com/news/3.html)

4. **战斗首先读懂“我、目标、法术路径”。** 2021-01 官方社交 PK 文章的同图战斗展示使用圆形人物/怪物肖像、外围阵圈与青色法术连接。**图像观察，且该图是带宣传装饰的战斗合成展示，不是未加工截图**。较新的 2023-12-08 更新公告则**明确写出**：战斗 UI 显示双方头像、气血、真元和状态，部分多人玩法显示自己与锁定目标的气血真元。**本项目建议**：平面角色标识保留清晰轮廓；当前目标增加独立框/环；HUD 优先展示自己和目标的真实 HP。现有后端没有传输的真元数值不虚构。[官方战斗展示文章](https://xian.leiting.com/news/17.html) · [展示图](https://xian.leiting.com/static/upload/editor/20210115/161069016436585503864082.jpg) · [官方战斗布局更新](https://xian.leiting.com/news/412.html)

5. **多人场景保留自角色表现，降低其他角色特效密度。** 2024-11-22 官方更新**明确说明**：多人战斗中其他人的领域神通改用低模；低特效设置下其他人的神通也简化。**本项目建议**：玩家、Boss、锁定目标保留完整脉冲与飞剑路径，其他单位优先保留位置、血条和少量短特效；淡雾与呼吸圈不能遮挡 HP。此策略适用于平面 SpriteRenderer，不意味着要恢复 3D。[官方性能优化公告](https://xian.leiting.com/news/604.html)
